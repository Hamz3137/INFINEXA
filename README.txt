INFINEXA — CYBER LEARNING THROUGH GAMIFICATION
==============================================

WHAT IS INCLUDED
- index.html: main website
- style.css: responsive dark cyber theme
- script.js: quiz interactions, XP, levels, achievements, local progress

RUN IT ON YOUR COMPUTER
1. Extract the ZIP file.
2. Open the extracted folder.
3. Double-click index.html.
4. The website opens in your browser. No installation is required.

PUBLISH IT ONLINE (EASY OPTION: NETLIFY)
1. Extract the ZIP file on your computer.
2. Open https://app.netlify.com/drop
3. Drag the extracted folder (the folder containing index.html) into the drop area.
4. Wait for deployment. Netlify will provide a public website URL.
5. Open that URL to show your project to others.

If the upload page asks for a ZIP instead, upload the ZIP file. If using another hosting
service, upload the contents of this folder to its static-site/public directory.

IMPORTANT
- This is a front-end demo website; it does not require a backend or API keys.
- Quiz XP and profile name are saved only in the current browser using localStorage.
- Sign in is a demo display-name prompt, not real account authentication.
- Leaderboard entries are sample data.
- Cybersecurity activities are awareness quizzes, not live attack tools.
- For a real multi-user login, cloud database, AI tutor, or shared leaderboard, a backend
  and hosting configuration will need to be added separately.
